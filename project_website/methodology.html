Methodology

Pneumonia classification was framed as binary classification on chest radiographs with a consistent train/validation/test pipeline across all models.

Dataset

Source and Structure

  • Dataset: Kaggle Chest X-ray Pneumonia
  • Classes: NORMAL, PNEUMONIA
  • Validation split: stratified from train

Architecture and Optimization

Input CXR 224x224
Transfer Backbone (ResNet18 / DenseNet121)
Binary Classifier (Linear -> Sigmoid)
  • Loss: BCELoss
  • Optimizer: Adam (weight decay 1e-4)
  • Scheduler: ReduceLROnPlateau
  • Early stopping: patience=3
  • Batch size: 32
