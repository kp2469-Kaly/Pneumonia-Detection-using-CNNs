About the Project

Pneumonia is a lung infection that can become life-threatening when diagnosis is delayed. Chest X-rays are commonly used for screening, but reading many images quickly can be difficult in real-world clinical workflows. This project explores how deep learning can support radiograph triage by classifying X-rays into two classes: NORMAL and PNEUMONIA.

The notebook focuses on practical model development: conservative augmentation, class-imbalance handling, transfer learning, and explainability with Grad-CAM. The final DenseNet121 checkpoint was selected based on held-out test ROC-AUC.

Image Setup

Resize to 224x224, grayscale converted to 3 channels for ImageNet-compatible backbones, then normalized with ImageNet mean/std.

Augmentation

Random horizontal flip (p=0.3) and random rotation (7 degrees) with conservative settings to avoid unrealistic distortions.

Imbalance Handling

WeightedRandomSampler on the training set to reduce class imbalance impact during mini-batch sampling.

Model Architecture and Optimization

  • Models compared: Baseline CNN, ResNet-18, DenseNet121
  • Loss: Binary Cross Entropy (BCELoss)
  • Optimizer: Adam with weight decay 1e-4
  • Scheduler: ReduceLROnPlateau (mode=min, factor=0.5, patience=1)
  • Early stopping: patience=3
  • Max epochs per model: 10
  • Batch size: 32
  • Learning rates: 1e-3 (baseline), 1e-4 (ResNet18, DenseNet121)

Training Process

1

Load and Split Data

Read Kaggle dataset, build a stratified validation split from training data, keep official test split untouched.

2

Preprocess and Sample

Apply transforms, then use WeightedRandomSampler for imbalance-aware batch generation.

3

Train Models

Train baseline CNN, ResNet-18, and DenseNet121 with shared evaluation protocol and per-model learning rates.

4

Validate and Select

Track train/val loss and accuracy, use scheduler + early stopping, compare held-out test metrics.

5

Explain and Save

Generate Grad-CAM visualizations and save best checkpoint based on ROC-AUC.
